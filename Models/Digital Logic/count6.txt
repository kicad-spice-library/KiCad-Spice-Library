* This is an example state.in file. This file
* defines a simple 2-bit counter with one input. The
* value of this input determines whether the counter counts
* up (in = 1) or down (in = 0).

0   0s 0s 0s 0 -> 0
             1 -> 1
1   0s 0s 1s 0 -> 1
             1 -> 2
2   0s 1s 0s 0 -> 2
             1 -> 3
3   0s 1s 1s 0 -> 3
             1 -> 4
4   1s 0s 0s 0 -> 4
             1 -> 5
5   1s 0s 1s 0 -> 5
             1 -> 0
